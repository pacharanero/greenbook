# greenbook

A Rust library and CLI that evaluates a patient's FHIR vaccination history against a computable, versioned representation of the NHS routine childhood immunisation schedule (the [Green Book](https://www.gov.uk/government/publications/immunisation-schedule-the-green-book-chapter-11)). See [spec/](./spec/) for the full specification, [docs/testing.md](./docs/testing.md) for a walkthrough of the POC, and [queries.md](./queries.md) for open design questions.
